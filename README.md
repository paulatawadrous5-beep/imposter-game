# 😈 لعبة المحتال — Imposter Game

لعبة جماعية حقيقية أونلاين لـ ٤ لاعبين: واحد محتال وكلمة سرية بالمصري.

**العب من هنا:** https://paulatawadrous5-beep.github.io/imposter-game/

## طريقة اللعب

1. واحد يعمل **غرفة جديدة** ويبعت الكود (٤ حروف) لصحابه.
2. الـ ٤ يدخلوا ويدوسوا **أنا جاهز** — اللعبة تبدأ لوحدها.
3. السيرفر يختار **محتال** عشوائيًا ويدي الكلمة السرية للـ ٣ التانيين بس.
4. كل واحد يقول **تلميح** من كلمة واحدة بالدور (المحتال بيحاول يبان عادي).
5. **تصويت سري**: مين المحتال؟
   - لو اتهمتوا المحتال صح → عنده فرصة أخيرة يخمّن الكلمة. خمّنها صح يكسب، غلط تخسروه.
   - لو اتهمتوا واحد بريء → المحتال يكسب فورًا.
   - لو مفيش إجماع (تعادل) → المحتال يكسب.
6. **العب تاني** من غير ما تعمل غرفة جديدة.

## المحتوى

| الملف | الوظيفة |
|---|---|
| `index.html` / `style.css` / `app.js` | واجهة اللعبة (عربي RTL، موبايل) — بتترفع على GitHub Pages |
| `server/server.js` | سيرفر اللعبة (Node.js + Socket.IO): الغرف، الأدوار، التصويت، التايمر |
| `server/words.js` | **قايمة الكلمات بالمصري** — ضيف وعدّل براحتك |
| `server/test.js` | اختبار آلي بـ ٤ لاعبين وهميين |
| `render.yaml` | إعداد الرفع على Render بضغطة واحدة |

## تشغيل السيرفر محليًا (للتجربة)

```bash
cd server
npm install
node server.js
# ثم افتح اللعبة بـ ?server=http://localhost:3000
```

## رفع السيرفر على Render (مجانًا)

1. اعمل حساب على [render.com](https://render.com) (ممكن تدخل بحساب GitHub).
2. من الـ Dashboard: **New → Blueprint** واختار ريبو `imposter-game`.
3. Render هيقرأ `render.yaml` لوحده — دوس **Apply**.
4. بعد ما يخلص (دقيقتين تقريبًا) هيديك رابط زي `https://imposter-game-server.onrender.com`.
5. عدّل سطر `SERVER_URL` في `app.js` وحط رابطك، أو ابعت لصحابك رابط اللعبة كده:
   `https://paulatawadrous5-beep.github.io/imposter-game/?server=https://imposter-game-server.onrender.com`

## حدود النسخة المجانية (مهم)

- **السيرفر بينام** لو مفيش حد بيلعب لمدة ١٥ دقيقة. أول واحد يدخل يستنى ٣٠–٦٠ ثانية لحد ما يصحى (اللعبة بتقول "بيصحّي السيرفر…").
- ٧٥٠ ساعة تشغيل شهريًا — كافية تمامًا للعب المتقطع.
- لو بتلعبوا كتير وعايزينه صاحي على طول: الخطة المدفوعة بـ $7/شهر.

## الخصوصية والأمان

- السيرفر **عمره ما بيبعت** الكلمة أو دور أي لاعب لحد غير صاحبه.
- التصويت سري — الأصوات بتتكشف بس في النتيجة النهائية.
- لو لاعب انقطع في نص الجولة: اللعبة بتقف وتستناه ٢ دقيقة يرجع بنفس جهازه.

## تعديل الكلمات

افتح `server/words.js` وضيف كلماتك بالمصري — سطر لكل كلمة — وارفع السيرفر تاني (Render بيعمل redeploy لوحده لما تعمل push).
